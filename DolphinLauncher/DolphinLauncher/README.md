# Dolphin Launcher — Launcher สำหรับ BYD Dolphin (DiLink)

Launcher หน้าตาสวย ธีมมืด/สว่าง สำหรับหัวเครื่อง BYD DiLink เขียนด้วย Kotlin + Jetpack Compose

## ระบบป้องกันค้าง
- **ตรวจจอค้าง:** ถ้าแอปไม่ตอบสนองเกินเวลาที่ตั้ง (ค่าเริ่มต้น 6 วินาที) จะบันทึกสาเหตุ เปิด Launcher เดิมของรถ แล้วปิดตัวเอง
- **ทำงานซ้ำผิดปกติ:** การเปิดแอป, เปิดกล้องไฟเลี้ยว, สร้างหน้าต่างลอย, เริ่มบริการ, สร้างหน้าใหม่, ปรับความสว่าง — ถ้าถี่เกินกำหนดจะหยุดทันที
- **BYD API:** อ่านไม่ถี่กว่า 250 ms · คำสั่งที่ error ติดกัน 3 ครั้งจะถูกปิด · ถ้าอ่านแต่ละรอบช้ากว่า 1.5 วินาทีติดกัน 3 รอบจะหยุดอ่านทันที · อ่านไม่ได้ต่อเนื่องจะลดความถี่เหลือทุก 5 วินาที
- **แอปเด้งซ้ำ:** 3 ครั้งใน 2 นาที → หยุด และปุ่ม Home ไปที่ Launcher เดิม
- เมื่อหยุด: เลิกอ่านข้อมูลรถและงานเบื้องหลังทั้งหมด แสดงหน้าสาเหตุพร้อมปุ่ม "เปิด Launcher เดิม", "เริ่มทำงานใหม่", "เริ่มใหม่ในโหมดจำลอง" และ "คัดลอกรายละเอียด"
- ทดสอบได้ที่ ตั้งค่า > สำรองข้อมูล & ระบบ > ทดสอบ: จำลองการหยุดทำงาน

## หน้าจอตามไฟหน้า
- ธีม "ตามไฟหน้ารถ": เปิดไฟหน้า = มืด, ปิด = สว่าง (อ่านไฟหน้าไม่ได้ → ใช้เวลาพระอาทิตย์)
- ความสว่างอัตโนมัติ: ตั้งระดับกลางวัน/กลางคืน และหน่วงเวลากันกระพริบ (ต้องอนุญาต "แก้ไขการตั้งค่าระบบ")
- ต้องตรวจ mapping บรรทัด `headlights` ด้วยเมนูสแกน BYD API

## ความปลอดภัย (อ่านอย่างเดียว)
- **เกียร์ R:** แอปปล่อยกล้องทันทีและไม่เด้งกล้องไฟเลี้ยว เพื่อให้กล้องถอยของรถทำงานได้เสมอ
  (ถ้า mapping เกียร์ยังไม่ถูกต้อง ให้แก้บรรทัด `gear` หรือเพิ่ม `reverse` ก่อนใช้งานจริง)
- **สแกน BYD API:** ค่าเริ่มต้นแสดงรายชื่ออย่างเดียว ไม่เรียกโค้ดของ BYD — การอ่านค่าต้องเลือกคลาสเองและทำได้ตอนจอดรถเท่านั้น
- **โหมดปลอดภัย:** ถ้าแอปเด้ง 3 ครั้งใน 2 นาที ปุ่ม Home จะเปิด Launcher เดิมของรถแทน เปิดแอปจากไอคอนเพื่อออกจากโหมดนี้
- แอปไม่ส่งคำสั่งใดๆ ไปที่รถ

## ขั้นตอนทดสอบที่แนะนำ
1. ลองบนมือถือ/แท็บเล็ต Android ด้วยโหมดจำลอง (ตั้งค่า > โหมดทดสอบ มีสวิตช์เกียร์ R ด้วย)
2. ติดตั้งในรถ แต่ยังไม่ตั้งเป็น Launcher หลัก เปิดแบบแอปธรรมดาตอนจอด
3. ทดสอบเข้าเกียร์ R ว่ากล้องถอยของรถขึ้นปกติ ทั้งตอนเปิดหน้ากล้องในแอปค้างไว้
4. ใช้งาน 2–3 วันไม่มีปัญหา ค่อยตั้งเป็นหน้าหลัก

## วิธี Build APK

### ทางที่ 1: GitHub (ไม่ต้องติดตั้งอะไรในเครื่อง)
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวม `.github`)
2. เข้าแท็บ **Actions** → workflow **Build APK** จะรันเอง (หรือกด *Run workflow*)
3. รอ ~5 นาที แล้วดาวน์โหลด **DolphinLauncher-apk** ในหน้าผลการรัน
   - `app-release.apk` (เซ็นด้วย debug key ติดตั้งได้ทันที) หรือ `app-debug.apk`

### ทางที่ 2: Android Studio
เปิดโฟลเดอร์นี้ใน Android Studio (Ladybug ขึ้นไป) → *Build > Build APK(s)*

## การติดตั้งและตั้งค่าในรถ
1. ติดตั้ง APK ลงหัวเครื่อง (ขึ้นกับเฟิร์มแวร์ว่าอนุญาตติดตั้งแอปภายนอกหรือไม่)
2. เปิดแอป → **ตั้งค่า > สำรองข้อมูล & ระบบ > เปิดหน้าตั้งค่าแอปหน้าแรก** เลือก Dolphin Launcher
3. **ตั้งค่า > การแจ้งเตือน > ขอสิทธิ์แสดงทับแอปอื่น** (จำเป็นสำหรับกล้องไฟเลี้ยวขณะใช้แอปอื่น)
4. เข้าหน้า **กล้องรอบคัน** กด *อนุญาต* สิทธิ์กล้อง แล้วกำหนดกล้องซ้าย/ขวา

## ⚠️ สำคัญ: การอ่านข้อมูลรถจริง (BYD Auto API)
BYD ไม่มี SDK สาธารณะ ข้อมูลรถ (ลมยาง ประตู เข็มขัด ไฟเลี้ยว ความเร็ว ฯลฯ) อยู่ในคลาสภายใน
`android.hardware.bydauto.*` ของเฟิร์มแวร์ ซึ่ง **ชื่อคลาส/เมธอด/เลขอาร์กิวเมนต์อาจต่างกันในแต่ละเวอร์ชัน**

ค่าเริ่มต้นในแอปเป็นค่าคาดการณ์ — ต้องตรวจสอบกับรถจริง:
1. ตั้งค่า > ข้อมูลรถ → เลือก **BYD Auto API**
2. กด **สแกน BYD API ในรถคันนี้** → *เริ่มสแกน* → จะเห็นคลาส เมธอด ค่าคงที่ ค่าปัจจุบัน และแพ็กเกจแอปกล้อง 360°
3. ลองเปิด/ปิดประตู คาด/ปลดเข็มขัด เปิดไฟเลี้ยว แล้วสแกนซ้ำ ดูว่าค่าใดเปลี่ยน
4. แก้บรรทัดใน **BYD API Mapping** ให้ตรง แล้วกด *บันทึก mapping* (ไม่ต้อง build ใหม่)

รูปแบบ mapping:
```
key = ชื่อคลาส#เมธอด(อาร์กิวเมนต์) | scale=0.01 | offset=0 | true=1 | map=1:P,2:R,3:N,4:D
```
keys ที่รองรับ: `speed soc range odometer power gear outside_temp tire_fl..tire_rr tire_temp_fl..tire_temp_rr door_fl door_fr door_rl door_rr trunk hood belt_driver belt_passenger passenger_occupied turn_left turn_right`

ถ้าสแกนพบชื่อ permission ของ BYD ที่ยังไม่มีใน `AndroidManifest.xml` ให้เพิ่มแล้ว build ใหม่
บางเฟิร์มแวร์อนุญาตเฉพาะแอประบบ — ในกรณีนั้นแอปยังใช้งานได้ในส่วน Launcher/ทางลัด/จับเวลา

กล้องรอบคัน (AVM) ในบางรุ่นถูกล็อกให้ใช้ได้เฉพาะแอปของรถ — ให้ใช้โหมด **"เปิดแอปกล้องของรถ"** แทน

## ทดสอบก่อนใช้ในรถ
เลือกแหล่งข้อมูล **โหมดจำลอง** แล้วไปที่ **ตั้งค่า > โหมดทดสอบ** เพื่อสั่งเปิดประตู ปลดเข็มขัด เปิดไฟเลี้ยว ปรับลมยาง ดูหน้าตาและการแจ้งเตือนได้ครบ (ใช้กับมือถือ/แท็บเล็ต Android ได้)

## โครงสร้างโค้ด
```
app/src/main/java/th/dolphin/launcher/
  App.kt                      ตัวแอป + ตัวแปรกลาง
  settings/AppSettings.kt     การตั้งค่าทั้งหมด (JSON)
  vehicle/                    สถานะรถ, โหมดจำลอง, BYD API (reflection + สแกน)

  apps/Apps.kt                รายการแอป, หน้าทางลัด

  ui/                         หน้าจอทั้งหมด (home, tires, camera, laps, apps, settings)
```
